# {{title}} — api-audit plugin

A scaffolded plugin for **api-audit**. Generated by `npx @flowot/nx-pn init {{id}}`.

## What it does

- Auto-fires one GET to `https://httpbin.org/get` on activation (attributed to `{{id}}`)
- Registers page at `{{path}}` (simple counter showing shared-React works)

## Build

```bash
npm install
npm run build   # produces dist/{{id}}.zip
```

The build script asserts:
- `host.js` keeps `cordis` external
- `browser.js` keeps React + react-router-dom external

## Install

Upload `dist/{{id}}.zip` to a running api-audit host:

```bash
npx @flowot/nx-pn add file:./   # npm-install path
# or
curl -F "zip=@dist/{{id}}.zip" http://localhost:4560/api/plugins
```

## Develop

Edit `host.ts` for server-side logic, `browser.tsx` for UI. Re-run `npm run build` after changes.

When the plugin is solid, publish to npm so users can install via `npx @flowot/nx-pn add {{id}}`.

## Files

| File | Purpose |
|---|---|
| `manifest.json` | Plugin contract (id, version, halves, pages) |
| `package.json` | npm metadata + `api-audit.manifest` for npm install path |
| `host.ts` | Server-side plugin (cordis plugin) |
| `browser.tsx` | UI page (React component) |
| `scripts/build-zip.mjs` | esbuild + zip builder with externals assertions |
| `tsconfig.json` | Extends monorepo base — adjust `extends` if outside the monorepo |
